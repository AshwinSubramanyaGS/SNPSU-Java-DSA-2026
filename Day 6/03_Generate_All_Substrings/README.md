# Generate All Substrings

Given a string `s`, return all possible non-empty substrings.

The order must be based on starting index and then ending index.

### Example 1
Input: `"abc"`  
Output: `["a","ab","abc","b","bc","c"]`

### Example 2
Input: `"ab"`  
Output: `["a","ab","b"]`

Return the substrings in this order.
