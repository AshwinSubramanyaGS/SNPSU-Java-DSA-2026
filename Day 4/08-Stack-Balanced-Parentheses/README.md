# 8. Stack – Check Balanced Parentheses

## Problem
Given a bracket string, determine whether (), {}, and [] are balanced.

## Files
- `Solution.java` — **student code**. Implement only the TODO method.
- `Main.java` — **test runner**. It calls the student's method through the exercise-specific `check()` method and compares the result.

## Run
```text
javac Solution.java Main.java
java Main
```

Do not modify `Main.java` while solving if you want to simulate the intended judge workflow.
