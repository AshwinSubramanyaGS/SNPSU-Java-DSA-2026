# Recursive Binary Search

Given a sorted integer array and a target, return the index of the target using recursive binary search. Return -1 when absent.

Do not use `Arrays.binarySearch`.

When duplicates exist, returning any matching index is acceptable.

Example: [1,3,5,7,9], target 7 -> 3.

## Method
`Solution.int binarySearch(int[] nums, int target)`

## Expectations
Solve the problem in `Solution.java`. Run `Main.java` to validate your implementation. Every group of three cases contains one explicitly marked edge case.
