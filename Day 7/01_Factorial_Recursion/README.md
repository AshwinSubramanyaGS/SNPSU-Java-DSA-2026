# Factorial Using Recursion

Given a non-negative integer n, return n! using recursion.

Requirements:
- Use a recursive design in `Solution.factorial`.
- Do not use loops.
- Base cases: 0! = 1 and 1! = 1.
- Assume 0 <= n <= 12 so the answer fits in int.

Examples:
- n = 5 -> 120
- n = 0 -> 1

## Method
`Solution.int factorial(int n)`

## Expectations
Solve the problem in `Solution.java`. Run `Main.java` to validate your implementation. Every group of three cases contains one explicitly marked edge case.
