# Fibonacci With Recursion + Memoization

Return the n-th Fibonacci number using recursion with memoization.

Use F(0)=0 and F(1)=1. The recursive solution should avoid repeated exponential work by caching already-computed values.

Constraints: 0 <= n <= 40.

This exercise is intended to reinforce recursion trees, stack depth, and the value of memoization.

## Method
`Solution.int fibonacci(int n)`

## Expectations
Solve the problem in `Solution.java`. Run `Main.java` to validate your implementation. Every group of three cases contains one explicitly marked edge case.
