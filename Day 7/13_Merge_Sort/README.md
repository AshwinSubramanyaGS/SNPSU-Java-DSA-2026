# Merge Sort

Sort an integer array in ascending order using merge sort.

Requirements:
- Implement divide, recursive sort, and merge logic yourself.
- Do not use `Arrays.sort` or `Collections.sort`.
- Return the sorted array. In-place modification is allowed.

## Method
`Solution.int[] mergeSort(int[] nums)`

## Expectations
Solve the problem in `Solution.java`. Run `Main.java` to validate your implementation. Every group of three cases contains one explicitly marked edge case.
