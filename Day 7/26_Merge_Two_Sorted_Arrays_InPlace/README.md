# Merge Two Sorted Arrays In-Place

You are given two sorted arrays `a` and `b`. Merge them into `a`, where `a` has enough trailing space to hold b's elements.

For example, a=[1,2,3,0,0,0], m=3 and b=[2,5,6], n=3 -> a=[1,2,2,3,5,6].

Fill from the back so existing values in a are not overwritten.

## Method
`Solution.void merge(int[] a, int m, int[] b, int n)`

## Expectations
Solve the problem in `Solution.java`. Run `Main.java` to validate your implementation. Every group of three cases contains one explicitly marked edge case.
