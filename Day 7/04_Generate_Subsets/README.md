# Generate All Subsets

Given an integer array with distinct values, generate all possible subsets using recursion/backtracking.

The output may be in any order. The empty subset must be included.

Example: [1,2] -> [], [1], [2], [1,2].

## Method
`Solution.List<List<Integer>> subsets(int[] nums)`

## Expectations
Solve the problem in `Solution.java`. Run `Main.java` to validate your implementation. Every group of three cases contains one explicitly marked edge case.
