# Recursive Palindrome Check

Return true when a string is a palindrome using recursion. Ignore case and non-alphanumeric characters.

Examples:
- "A man, a plan, a canal: Panama" -> true
- "race a car" -> false

Do not use loops for the core palindrome check.

## Method
`Solution.boolean isPalindrome(String s)`

## Expectations
Solve the problem in `Solution.java`. Run `Main.java` to validate your implementation. Every group of three cases contains one explicitly marked edge case.
